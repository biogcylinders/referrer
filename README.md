One last thing that I think would move signups the most

Right now your CTA is:

Become a Referrer

I'd test changing it to:

Review Your First Candidate

See How Candidate Review Works

Preview a Candidate Profile

Why?

Because "Become a Referrer" feels like a commitment.

"Review Your First Candidate" feels like trying the product. Reducing perceived commitment often increases clicks because users don't feel they're signing up for a responsibility before they've seen the value.
